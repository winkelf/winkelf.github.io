Toys versus Wilks

A walkthrough of a small Python script that fits the signal strength μ of a Gaussian bump on a falling background, then tests each value of μ two ways: by throwing toy experiments, and with the asymptotic formula that follows from Wilks' theorem.

Best fit, observed dataμ̂ from L-BFGS-B, μ ≥ 0
95% CL upper limit (toys)where p crosses 0.05
95% CL upper limit (Wilks)p = 1 − Φ(√q)
Toys per μ40 μ values from 1 to 2

1The model

The observable x runs from 0 to 10 in 30 bins. The background is an exponential with τ = 2.0, sampled by inverting its truncated CDF. The signal is a Gaussian resonance at x = 3.0 with σ = 0.30. 20,000 background and 100 signal events are drawn and fill the b and s templates. These templates act as the theory prediction.

A second, independent draw with the same sizes is the "measurement" n_obs_obs. It is fitted against the fixed templates.

The sliders below set these five parameters. Moving one, or asking for a new random draw, re-simulates the templates and the measurement and redraws the two plots in this section. They start at the script's values, with the script's seed (124), so the plots match its output. Sections 2 to 5 always use the script's model, because the toy scan behind them was run once, offline.

2The binned Poisson likelihood

Each bin is an independent Poisson count with mean νi = μ·si + bi. The log-likelihood adds up the bins:

\[ \ln L(\mu) \;=\; \sum_{i=1}^{30} \Big[\, n_i \ln\!\left(\mu s_i + b_i\right) \;-\; \left(\mu s_i + b_i\right) \Big] \;=\; \sum_{i} \Big[\, n_i \ln \nu_i - \nu_i \Big] \]

    nu = mu * s + b
    nu = np.clip(nu, 1e-12, None)
    logL = np.sum(n * np.log(nu) - nu )#- gammaln(n + 1)

The ln n! term is commented out. That is safe, because it does not depend on μ and cancels in every likelihood ratio below. The clip protects the log in empty bins.

fit_mu minimizes −ln L with L-BFGS-B, with the physical bound μ ≥ 0. On the template dataset itself (n = s + b, which the script calls the Asimov dataset) it returns μ̂ = , as it should. On the independent measurement it returns μ̂ = .

3The test statistic qμ

To test a value μ, the script compares the likelihood at that μ with the best one. It uses the one-sided form for upper limits, where data that fit a signal larger than μ are not evidence against μ:

\[ q_\mu \;=\; \begin{cases} -2 \ln \dfrac{L(\mu)}{L(\hat\mu)} & \text{if } \hat\mu \le \mu \\[1.2ex] 0 & \text{if } \hat\mu > \mu \end{cases} \]

Writing out both likelihoods with νi = μ·si + bi shows every ingredient at once:

\[ q_\mu \;=\; -2 \sum_{i=1}^{30} \left[\, \class{v-n}{n_i} \,\ln \frac{\class{v-mu}{\mu}\,\class{v-s}{s_i} + \class{v-b}{b_i}}{\class{v-mu}{\hat\mu}\,\class{v-s}{s_i} + \class{v-b}{b_i}} \;-\; \big(\class{v-mu}{\mu} - \class{v-mu}{\hat\mu}\big)\, \class{v-s}{s_i} \,\right] \qquad \text{for } \hat\mu \le \mu \]

The templates s and b are fixed once and for all, and μ is the hypothesis we choose. Only n comes from an experiment, and μ̂ follows from n. So for a given μ, qμ is a function of the counts alone. That is what section 4 exploits: it keeps s, b and μ, swaps in a new set of counts thousands of times, and records the qμ each one gives. For the measurement, μ̂ = , so qobs is 0 for every μ below that and grows above it.

4Toy experiments

A single qobs means nothing until you know how qμ is distributed when μ is true. Every toy starts from the prediction for the tested μ, ν = μ·s + b. The background template stays fixed, and μ only scales the signal on top of it. At μ = 0.01 there is almost no resonance, at μ = 1 there is the nominal signal, and at μ = 2 there is twice the nominal signal.

For every tested μ, generate_toys fluctuates each bin of μ·s + b with its own Poisson draw. Each toy is refitted for its own μ̂, and its qμ is computed exactly as for the data. The p-value is the fraction of toys that come out less compatible than the data:

pμ = P( qμtoy > qμobs )   →   pval = np.mean(q > qobs)

5Wilks' theorem and the upper limit

Wilks' theorem says that −2 ln λ approaches a χ² distribution with one degree of freedom for one parameter when the sample is large. For the one-sided qμ, half the probability sits at exactly zero and the other half follows χ²₁. That gives a closed form with no toys:

pμ ≈ 1 − Φ( √qμobs )

With about 700 events per bin near the peak, this sample is far into the asymptotic regime, and the two methods agree within toy statistics. The μ where p drops below 0.05 is the 95% CL upper limit on the signal strength.

Aca estan las funciones (nada raro, solo el calculo de las likelihoods, la minimizacion de logL, generacion de toys y plotting)
'''

def poisson_likelihood(mu, n, s, b, log=True):

    n = np.asarray(n)
    s = np.asarray(s)
    b = np.asarray(b)

    # expected counts
    nu = mu * s + b

    # protect against zeros
    nu = np.clip(nu, 1e-12, None)

    # log-likelihood for independent Poisson bins
    logL = np.sum(n * np.log(nu) - nu )#- gammaln(n + 1)

    if log:
        return logL
    else:
        return np.exp(logL)

def fit_mu(n, s, b, mu_initial=1.0):

    # function to minimize
    def neg_logL(mu):
        mu = mu[0]
        # enforce mu >= 0
        if mu < 0:
            return np.inf
        return -poisson_likelihood(mu, n, s, b, log=True)

    # run minimization
    result = minimize(
        neg_logL,
        x0=[mu_initial],
        bounds=[(0, None)],       # mu >= 0
        method='L-BFGS-B'
    )

    return result

def generate_toys(mu_test, bg_events, sig_events, bins, xmin=0, xmax=10, N_toys=1000):

    # Template histograms
    b, bin_edges = np.histogram(bg_events,  bins=bins, range=(xmin, xmax))
    s, _         = np.histogram(sig_events, bins=bins, range=(xmin, xmax))

    # Compute expected counts for this test mu
    nu = mu_test * s + b

    # Protect against numerical issues
    nu = np.clip(nu, 1e-12, None)

    # Generate toys: each bin independently Poisson-fluctuated
    toys = np.random.poisson(lam=nu, size=(N_toys, len(nu)))

    return toys, s, b

def plotToy(toyn):
    toy = toys[toyn]
    # Recreate bin edges (same as histogram)
    bin_edges = np.linspace(0, 10, 31)   # 30 bins → 31 edges
    bin_centers = 0.5*(bin_edges[1:] + bin_edges[:-1])
    
    plt.figure()
    plt.bar(bin_centers, toy, width=(10/30), alpha=0.5, label='Toy')
    plt.title("Toy bkg model")
    plt.xlabel("Observable x")
    plt.ylabel("Counts")
    plt.tight_layout()
    plt.legend()

How the numbers on this page were made: the templates and the measurement were regenerated with the script's seed (124) and draw order, so they match the script's output. The toys were then rerun with toys per μ instead of the script's 100,000, which puts a statistical uncertainty of about ±0.003 on a toy p-value near 0.05. The asymptotic curve and both upper limits come from the same scan, interpolated linearly in log p.
