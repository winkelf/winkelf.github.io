Chapter 1 · No-arbitrage pricing in discrete time

Pricing and replicating a European call

The stock moves up by a factor u or down by d each period, and cash earns a simple rate r per step. Backward induction under the risk-neutral probability gives the call's fair value at every node. A self-financing portfolio that holds Δ shares and starts with X₀ then tracks the call. It replicates the payoff exactly when X₀ equals the fair price V₀; any surplus or deficit just grows in the bank.

The four formulas behind the page

Risk-neutral probability

q = (1 + r − d) / (u − d)

The probability under which the discounted stock is a martingale. No arbitrage is exactly the condition 0 < q < 1.

Backward induction

Vt = [q Vup + (1−q) Vdown] / (1+r)

Start from the payoff max(SN − K, 0) and step back one period at a time.

Delta hedge

Δt = (Vup − Vdown) / (Sup − Sdown)

For a call 0 ≤ Δ ≤ 1: the hedge is long the stock and borrows cash.

Wealth of the hedge

Xt = Vt + (X₀ − V₀)(1+r)t

Holding the call's Δ with the wrong starting capital leaves the gap in the bank, where it earns interest.

Chapter 2 · Probability theory on coin-toss space

Expectation, martingales and the Markov property

Toss a coin N times. Each outcome ω is a string of H and T, and every random quantity in the binomial model, from the stock price Sn to an option payoff or a running maximum, is a function of ω. This chapter asks four questions about such a function X: what is its average, what is the best forecast of it given the tosses seen so far, when is that forecast already today's value, and how much of the past the forecast really needs.

Model

Same binomial stock as Chapter 1. Up = heads, down = tails.

Probability measure

Martingales: no expected drift

Section 2.4

A process Mn is a martingale when the best forecast of the next value is the current value: En[Mn+1] = Mn at every node. Each box shows Mn and, beneath it, the expected change over the next toss. Green rises on average, red falls, grey stays put.

The Markov property: how much memory a forecast needs

Section 2.5

A process is Markov when the forecast of anything in its future depends only on where it is now, not on the path that led there. Group the paths at time n by a candidate state. If every path in a group gives the same forecast En[X], the forecast is a function gn of the state and the state carries all the memory you need.

The four definitions behind the page

Expectation

E[X] = Σω X(ω) P(ω)

On coin-toss space P(ω) = p#H(ω)q#T(ω). Changing p to p̃ reweights the same outcomes.

Conditional expectation

En[X] = p En+1[X]H + q En+1[X]T

A random variable that depends only on the first n tosses, with E₀[X] = E[X] and EN[X] = X.

Martingale

Mn = En[Mn+1]

Then E[Mn] is constant in n. Replace = with ≤ for a submartingale and ≥ for a supermartingale.

Markov process

En[f(Xn+1)] = g(Xn)

For every f there is a g. Pricing then needs one value per state, not per path: vn(s) = [p̃ vn+1(us) + q̃ vn+1(ds)]/(1+r).
